---
title: "Excluir lead"
api: "DELETE /user/leads/{id}"
description: "Exclui permanentemente um lead específico do sistema OmniTech a partir do ID, removendo seus dados de contato e variáveis de campanhas associadas."

Este endpoint permite excluir um lead do sistema OmniTech.

### Parâmetros de Caminho

<ParamField path="id" type="integer" required>
  ID do lead a ser excluído
</ParamField>

### Resposta

<ResponseField name="message" type="string">
  Mensagem da resposta
</ResponseField>
